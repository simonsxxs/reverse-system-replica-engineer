# 03 · 建造规范

## 一、复刻栈决策矩阵（阶段 1 确认，写入 GOAL）

| 目标类型 | 首选复刻栈 | 理由 | 备选 |
| --- | --- | --- | --- |
| 无框架 MPA/多页站 | **按原架构**：多页静态 HTML + 原生 JS + 原样式令牌 + Express/SQLite 伺服 | DOM/样式可逐位对照，走样风险最低 | Vue 多页（用户指定时） |
| 组件化 SPA | 对齐原框架与版本（Vue→Vue3+对应UI库；React→React） | 交互语义天然对齐 | 按原架构自绘（工作量大，慎选） |
| 管理后台（iframe+多标签） | 同目标形态：主框架+iframe+页签路由 | 交互语义一致 | — |
| Electron 桌面 | 复刻为 Web 应用（推荐） | 跨平台、审查工具链通用 | Electron（需保留桌面特性时） |
| 原生桌面/移动 | 复刻为 Web 应用为主选 | 1:1 指 UI 观感与交互逻辑，不是二进制等同 | 原生（用户明确要求时） |

原则：**1:1 指用户可见的 UI、交互与功能行为 1:1**，不是源码等同；服务端按抓包契约等价实现（同路径同结构）。

## 二、结构性重写红线（返工率最高的一条）

- 复刻代码**禁止照抄**：剥注释后与原站相似度 <40%，且无 ≥7 行成段业务逻辑重合（语句级逐字保留即使改了变量名也算违规——有实证判例：99% 重合判 FAIL，仅剩契约串判 PASS）。
- **仅改注释不算重写**。合规手法：函数边界重排、内部符号系统性改名、实现路径替换（字符串拼接→模板函数、回调→箭头+查表、长 if 链→表驱动）、DOM 构建分块。
- **允许的重合**：CSS 值声明、文案字面量、接口路径/参数契约串、DOM 结构模板、图标映射——这些是「契约面」而非逻辑。
- **自证口径统一**：直接运行 `node <skill>/scripts/similarity.mjs <复刻文件> <原型文件>`（剥注释+LCS+原型行分母）；自写口径曾产生 4.6pp 背离（判例）。交付物附脚本运行输出。
- **零配对护栏与覆盖率（v1.2）**：某对零行重合且词面亲和度 <0.30 → 脚本判 FAIL（zero-pair，疑似拿错原型/配对断裂）；零行重合但亲和度 ≥0.30 → 不判 FAIL 但输出警告，须人工复核逻辑等价并配合行为断言；目录模式下零对文件进入比对同样判 FAIL。报告含 **coverage**（已配对原型行数/全部原型行数）——coverage <100% 说明原型侧大块内容未进入比对（改名未映射/目录错位），不得只看整体重合率；文件改名导致的配对断裂用 `--map mapping.json`（`{"复刻相对路径":"原型相对路径"}`）提供改名映射后重测。
- **能力边界**：文本相似度**无法检测逻辑等价重写**（换语言重写、算法替换、逐语句语义等价但表达不同）——相似度达标 ≠ 行为一致，必须与行为断言（逐功能实测/接口契约逐字段/0 pageerror，见 04）配合，两者都过才算重写合规。
- 超线处置：结构性重排后用审查脚本+零回归比对收口；贴线件（>35%）登记警戒。

## 三、页面转换三策略

1. **复杂静态页**（插画/画布/长表单）：DOM→HTML 字符串模块注入（v-html 式），交互用事件委托——绕开模板编译限制；
2. **交互重页**（工作台/编辑器）：手写组件/模块，类名结构照搬原 DOM；
3. **原站 DOM 缺失页**：按截图+JS 包文案手工重建，登记为材料边界。

## 四、样式与运行时行为移植清单（血泪经验逐条执行）

- 剥 data-v 会降 CSS 特异性 → 被反超时用 `:not(#z)` 补强；`@media`/`@container` 必须保留包裹；
- 高度链：页面根→布局容器逐级 `height:100%`，底部固定栏才能钉住；
- 图标字体文件要拿到手（或等价替代），字体 404 做全站排查；
- 运行时行为需补接：开关类 aria-pressed、禁用按钮"输入后启用"、日期默认值、懒加载分包 CSS；
- 失效外链图片（blob:/OSS）换本地占位或渐变；设计令牌（CSS 变量）原样沿用保证配色一致；
- 404/未开通等门禁页**照实复刻**并注册在布局外。

## 五、后端与数据

- mock 后端按抓包契约实现：同路径、同请求/响应结构（值级/指纹比对验收）；实测不到的写操作按**推断契约**实现并逐条登记（前端消费面反推），汇总成「待真实环境验证清单」；
- 业务 CRUD 真实生效（SQLite/文件均可）；AI 生成/外部对接/支付一律**模拟运行**（确定性模板产出，零真实调用零费用）；
- **演示开关模式（逐态标注，v1.2.1 修正）**：默认态=抓包时点态，证据=**原站抓包文件**（逐开关引采集文件路径）；env 开关置 1=演示解锁态，证据=**推断依据（引登记项）+ 模拟验证结果（引自测套件）**。两态证据等级不同——默认态是采集实证、解锁态是推断+模拟验证，逐态标注不得互冒，也不是缺陷开关；
- 计费/账本类照实分离（判例：积分与媒体钱包双账本物理分离）；余额闸、限流降级文案等防护逻辑照实实现；
- 接口层做成可切换：后续接真实 API 时按域替换，前端零改动；
- 凭据：管理员账号独立生成存 gitignore 的 .env，**缺配置启动即报错**（禁止兜底默认值——有口令泄漏判例）。

## 六、公共件纪律

- 全站公共件（导航/弹窗/品牌/计费/图标/图表）在第一批建好，后续批次只复用不重写；
- 公共件的**绑定机制选择要对照原站**（判例：onclick 属性 vs addEventListener 差异导致"失败关弹窗"行为漂移，修复需全站排查）；
- 公共件被授权改动时（如白标定制），必须回归受影响页面；
- 品牌双轨类细节照材料：同一站内"登录页品牌名"与"业务品牌名"可能来自不同接口（判例：brand vs branding 双轨），分开实现勿合并。

## 七、跨页联动（功能逻辑可运行的深水区）

- 跨页任务链（A 页建任务→B 页审核→C 页联动出现）必须端到端实测，不是各页各自为政；
- 数据持久化跨重启验证（重启后状态仍在才算真 CRUD）；
- 嵌入式子应用（iframe + postMessage 消息面）作为独立交互面采集与实测。

## 八、每批交付物

1. 实现说明（文件清单/接口对照表实测推断分列/交互清单/自验记录/差异登记/交接项）；
2. 自测套件（断言可重放，含删库冷启动与重启持久）；
3. 相似度自证（`scripts/similarity.mjs` 运行输出）；
4. 差异登记（含站方 Bug 照实项——每条注明证据）。
