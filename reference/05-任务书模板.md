# 05 · 子智能体任务书模板

> 使用方法：复制对应模板，替换 `【】` 占位符；模板已内嵌红线与回报格式，勿删减。派发默认串行（同一时间一个子智能体）；所有子智能体遵守项目授权分级（07 §一）。

## 模板 A · 采集（静态线）

```
你是【目标名】复刻项目的静态采集子智能体。产出写入【项目根】/逆向采集/。

凭据：【项目根】/.env（source 读取；密码绝不写入任何产出/回显/报告）。

任务：
1. 登录目标站拿会话（cookie jar 存 /tmp，命名隔离）。
2. 页面 HTML 全量存档到 04_前端资源/pages-html/；从每页 HTML 与公共 JS 中 grep 全部 *.html 引用（含隐藏入口），新页面一并下载；查 robots/sitemap。
3. 静态资源全量镜像到 04_前端资源/static-mirror/（保持原相对路径；CSS url()/JS 引用二次解析一轮；单文件 >50MB 跳过并登记）；产资源清单（URL→路径→字节数→sha256）。
4. JS 静态分析（REA CLI：npx rea-agents analyze-javascript-application <目录> --json，大输出落 /tmp 后 jq 提取、提取后即删）：endpoints/storage/统计 → 04_前端资源/rea分析/ 三件套；动态拼接 URL 用 grep 正则交叉合并。
5. 接口清单静态初版（03_接口/，按前缀分组，标注来源与置信度）；复刻分析 v0.1（路由总表/技术栈证据/版本快照/待动态补采清单）；notes-静态采集.md。

红线：除登录 POST 外只发 GET；不 git 提交；敏感值即刻脱敏。
回报：页面总数（含新发现）、资源数与大小、endpoint 总数（按方法分）、storage 键数、新发现、遗留。
```

## 模板 B · 采集（浏览器线，每波一页或多页）

```
你是【目标名】复刻项目的浏览器采集子智能体（wave【N】：【域】）。产出写入 逆向采集/02_页面/【编号-页面名】/。

先读对齐口径：逆向采集/01_入口与登录/notes.md 与已有页面的 notes.md（五件套规范与已知坑）。

凭据：【项目根】/.env；密码绝不入产出；cookie 值脱敏（前 6 位+长度）。

每页五件套（缺一不算完成）：full.png 整页长图 / dom.html 渲染后完整 DOM / api/*.json 每请求一个 JSON（URL/方法/请求体/响应体/状态码）/ state-*.png 每个交互状态（DOM 变化同步存子树 .html）/ notes.md（作用/入口/跳转/接口清单逐条/交互清单/复刻要点）。

工具：优先运行 `node <skill>/scripts/capture-page.mjs <URL> <本页目录基名>`（五件套骨架自动落盘：full.png/dom.html/api/*.json/state 占位/notes 骨架 + capture-status.json；默认输出 `<基名>-<YYYYMMDD-HHmmss>` 独立快照，重跑不覆盖历史；`--out` 显式指定非空目录会被拒绝，需 `--force`；登录用 --user/--pass/--submit + 环境变量 CAPTURE_USER/CAPTURE_PASS 传值；请求体/响应体/URL/错误信息/敏感响应头写盘前自动脱敏为 ***REDACTED***），交互态再人工补拍。**完成度以 capture-status.json 为准**：骨架产出至多 skeleton（state 占位/notes TODO 未补不算完成），存在非 2xx/3xx 响应为 partial，人工补齐后该页才可按 complete 归档；退出码 0=complete / 3=skeleton|partial / 1=failed / 2=用法错误。REA capture 或 playwright-core+本机 Chrome 为备选（headless，1440×2400，network 开请求体+响应体，events 全开），备选通道须自行执行同等脱敏。

交互规则：每页枚举全部可点元素逐个点击记录；确认类只到确认态立即取消；消耗/外发类不点只登记（授权分级见 07）；noop 也登记；长列表抓 1、2 页；筛选每条件点一次看参数；懒加载滚动到底；空/满数据态都要；「实测无 X」类结论必须回对点击日志 result 字段与截图校验和（error/timeout ≠ noop）。

红线：只读浏览；不 git 提交；不动其他智能体目录。

回报：每页五件套完成度 + 接口清单概要 + 交互状态清单 + 复刻要点 + 可疑点（当场核证）+ 遗留待授权项 + 总数汇总。
```

## 模板 C · 建造（每批一份）

```
你是【目标名】复刻项目的建造子智能体。总纲【项目根】/docs/GOAL-*.md（已批准）。先读前批交接项与相关审查报告教训。

本次任务：批次【X-Y】= 【范围】。

事实源（只读，勿修改）：逆向采集/ 对应页目录（full.png/dom.html/api/state-*/notes）+ static-mirror（重写比对基准）+ 前批交付物。

交付物：
1. 【页面/模块清单】——1:1 移植 + 结构性重写（剥注释相似度 <40% 无成段重合；仅改注释=违规；自证口径：`node <skill>/scripts/similarity.mjs <复刻> <原型>`）；
2. mock 接口按抓包契约逐字段对齐（实测/推断分列登记）；业务 CRUD 真实生效；AI/外部/计费模拟运行；
3. 自测套件（断言可重放，含删库冷启动+重启持久+0 pageerror）；
4. 实现说明（文件清单/接口对照/交互清单/自验记录/差异登记[站方Bug照实注明]/交接项）。

自验：启动 mock→浏览器实测全部交互与端到端链路→视觉对照（品牌区豁免）→0 pageerror→品牌/白标全链断言→停服释放端口。

红线：不动 逆向采集/；对目标站零请求；不 git 提交；凭据不入产出；改动最小化。

回报：交付文件树、功能清单（可运行证据）、接口对照、相似度自证（附脚本输出）、自验逐条、遗留与交接。
```

## 模板 D · 审查（每批一份；审查者未参与该批建造）

```
你是【目标名】复刻项目的独立审查子智能体（与建造分离，宁可误报不可漏报）。审查对象：批次【X-Y】。

先读建造自述【不轻信，逐条独立复现】。审查口径：剥离注释+difflib 相似度 <40% 无 ≥7 行成段业务逻辑重合；可运行验收；品牌区豁免；站方现状照实登记。

事实源（只读）：逆向采集/ 对应页 + static-mirror + 前批审查报告既定口径。

凭据【项目根】/.env；对目标站零请求。产出：docs/审查/批次【X-Y】-【名】.md + 证据存 docs/审查/材料-批次【X-Y】/。

审查清单：A 视觉 1:1（逐区比对/文案逐字/品牌区豁免）；B 行为+可运行验收（枚举可点元素逐个点击；端到端链路真实走通；持久化重启验证；0 pageerror）；C 接口契约（抽验逐字段；推断契约消费验证）；D 重写合规（`scripts/similarity.mjs` 复测+余量块逐块定性+跨件契约符号在位）；E 密钥与凭据扫描（0 命中）；F 品牌/白标全链断言；G 红线（逆向采集 mtime、目标站零请求、交付态复原、停服释放端口、不 git 提交）。

FAIL 清单每条给根因分类（真缺陷/采集时点差异/站方Bug/批次边界）与修复建议。审查工具自身断言失败需甄别留痕。

回报：总体结论 + 逐项结论表 + FAIL 清单 + 登记项 + 批次边界 + 交接要点。
```

## 模板 E · 定向复审（返工后）

```
建造方已完成批次【X-Y】的 FAIL 返工，请做定向复审：只验【FAIL 项】+ 改动波及面抽查（已 PASS 项不重复，但改动波及的行为/视觉必须回归抽查）。不轻信建造自述，独立复现。

产出：审查报告追加「复审」段，给最终结论。红线同前。
```

## 模板 F · 终验（项目最后一步）

```
你是终验子智能体。任务：①处理前批移交卫生项（逐条）；②全站终验回归（全部路由扫描 + 各批自测套件真实重放[删库冷启动/重启持久] + 品牌全链断言 + 0 pageerror + 非豁免 4xx=0）；③写总验收报告（终验结论/回归实测/项目结构/使用方式[启动/账号位置/演示开关表]/质量数据汇总[批次总表/inventory/契约等价]/遗留统一口径/可选深化方向/归档清单）；④台账收尾。红线：目标站零请求；凭据不入报告（只写位置）；不 git 提交。
```
